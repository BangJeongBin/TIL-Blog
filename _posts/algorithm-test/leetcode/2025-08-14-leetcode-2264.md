## Description
---
You are given a string `num` representing a large integer. An integer is **good** if it meets the following conditions:

- It is a **substring** of `num` with length `3`.
- It consists of only one unique digit.

Return _the **maximum good** integer as a **string** or an empty string_ `""` _if no such integer exists_.

Note:

- A **substring** is a contiguous sequence of characters within a string.
- There may be **leading zeroes** in `num` or a good integer.

<br>

### Example 1
---
- **Input:** num = "6**777**133339"
- **Output:** "777"
- **Explanation:**
	- There are two distinct good integers: "777" and "333".
	- "777" is the largest, so we return "777".

<br>

### Example 2
---
- **Input:** num = "23**000**19"
- **Output:** "000"
- **Explanation:** "000" is the only good integer.

<br>

### Example 3
---
- **Input:** num = "42352338"
- **Output:** ""
- **Explanation:**
	- No substring of length 3 consists of only one unique digit. Therefore, there are no good integers.

<br>

### Constraints
---
- `3 <= num.length <= 1000`
- `num` only consists of digits.

<br>

### Hint
---
<details>
	<summary>Hint 1</summary>
	<pre>
  We can sequentially check if “999”, “888”, “777”, … , “000” exists in num in that order. The first to be found is the maximum good integer.
	</pre>
</details>

<details>
	<summary>Hint 2</summary>
	<pre>
  If we cannot find any of the above integers, we return an empty string “”.
	</pre>
</details>

## Code
---
### 내 제출
---
```java
class Solution {
    public String largestGoodInteger(String num) {
        for (int i = 9; i >= 0; i--) {
            String s = String.valueOf(i).repeat(3);
            if (num.contains(s)) {
                return s;
            }
        }
        return "";
    }
}

```

```java
class Solution {
    public String largestGoodInteger(String num) {
        String[] toFind = new String[]{"999", "888", "777", "666", "555", "444", "333", "222", "111", "000"};
        for (String ans : toFind) {
            if (num.contains(ans)) return ans;
        }
        return "";
    }
}

```
